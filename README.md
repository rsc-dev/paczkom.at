# paczkom.at

A courier, a crate and a parcel locker, on a little LCD handheld. Someone on a
balcony is throwing parcels; run underneath, catch them in your crate and carry
them to the locker before the crate overflows. It speeds up as you go.

The look and the rules are a tribute to the 1980s/90s LCD handhelds that Polish
players remember as "Jajka". The scenery, parcels, drone and bird are cut from
the owner's own ink drawing (`scripts/art/source/board-1.png`); the courier and
the thrower are placeholders until their drawing arrives. There is no wolf and
no hare, and the machine is a generic *automat paczkowy*.

No backend, no accounts, no tracking, no runtime dependencies: a static page of
hand-written TypeScript, CSS, one SVG and a handful of PNG sprites.

## How to play

- The courier stands at one of five places. The first four are under the four
  spots where parcels land; the fifth, at the far right, is the locker.
- Move with the two round buttons, by tapping the left or right half of the
  screen, or with **A/D** or **←/→**. Numpad **1–5** jump straight to a place.
  **Space** or **Enter** starts Gra A, **B** starts Gra B, **CZAS** (TIME)
  shows the clock.
- Stand under a parcel when it comes down to catch it. The crate holds three;
  with a full crate you cannot catch, so run to the locker: every parcel
  delivered is **2 points**.
- A parcel nobody catches breaks and costs a heart. Three hearts; losing the
  last ends the shift. Hearts refill at 100 and 300 points.
- From level 2 a bird sometimes sits on a flight path and knocks a parcel to
  the next spot; from level 3 a drone drops extra parcels straight down.
- Levels rise at 16, 32, 48 and 72 points. **Gra A** starts at level 1,
  **Gra B** at level 3. The display wraps after 999.
- Your record for each game is kept in this browser. At the end of a shift you
  can share your score.
- Leaving the tab pauses the game; coming back resumes it.

## Requirements

- Node `^20.19 || >=22.13` and npm

## Install

    npm ci

For the end-to-end suite, also fetch the browser it drives:

    npx playwright install --with-deps chromium

## Develop

    npm run dev

- `npm run gen:icons` — regenerate the icons and the link-preview `og.png`.
- `npm run gen:art` — cut the sprites in `public/sprites/` out of the art boards
  in `scripts/art/source/` (needs ImageMagick's `magick`). Crop boxes and the
  areas to blank out are listed in `scripts/art/sprites.ts`; the PNGs are
  committed, so only run this after changing a board or a box.

The rules live in `src/core/game.ts` (a pure reducer with seeded randomness);
the LCD is generated by `src/ui/lcd-art.ts`, where every parcel position,
courier place and digit segment is a fixed SVG element (mostly a sprite) that
the game only switches on and off, like a real LCD.

## Build

    npm run build

## Deploy

`deploy.yml` deploys to GitHub Pages after a green CI run on a push to `main`
from this repository, and on demand (which deploys `main`). There is no
schedule.

GitHub Pages settings: source **GitHub Actions**, custom domain `paczkom.at`,
**Enforce HTTPS** on. DNS at OVH: apex A/AAAA to GitHub Pages, `www` CNAME to
`rsc-dev.github.io.`

## A note on the name

"Paczkomat" is a registered trade mark of a parcel-locker operator. This site is
not affiliated with any of them, uses none of their branding, and a test keeps
the word out of every page and string.
