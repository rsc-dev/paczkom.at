# LCD Courier Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the air-quality card on paczkom.at with an LCD-handheld arcade game: a courier catches parcels sliding down four chutes into a parcel locker (Game A / Game B, local record, share score).

**Architecture:** A pure reducer in `src/core/game.ts` owns the rules (ticks, catches, complaints, customer, tempo) with seeded randomness (`src/core/rng.ts`, restored from tag `game-final`). The LCD is one SVG generated by `src/ui/lcd-art.ts` where every drawable is a segment with a stable id; `src/ui/lcd.ts` turns a view of the game into the set of lit segment ids and toggles `data-on`. `src/main.ts` runs the timers, input, sound, record and sharing.

**Tech Stack:** TypeScript 6, Vite 8, Vitest 4 + jsdom, Playwright, Web Audio. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-10-lcd-courier-design.md`

**Work in:** `/home/surtr/projects/paczkom.at-lcd` (branch `lcd-game`, from `origin/main` 00e555e).

**Deviations from the spec, decided while planning:**
- The LCD has **four** 7-segment digits, not three: the clock needs HH:MM. Scores use the right three.
- The share text drops the "💥 3 reklamacje" line: a shift always ends at exactly three complaints, so the line never changes.
- After a miss the board is cleared (all parcels removed) before the pause ends — the spec is silent; this avoids a cascade of misses after one mistake, as on the original handhelds.
- At most one parcel spawns per tick, so two parcels never reach their lips on the same tick (every parcel is catchable).

## Global Constraints

- No runtime dependencies; `package.json` `dependencies` stays empty.
- `src/core/**` is pure: no `Math.random`, `Date.now`, DOM, `fetch`; randomness only through `src/core/rng.ts`.
- No colour literals in `src/core/**` or `src/ui/**`; colours live in `src/theme/*.css` (scripts may name colours).
- Never "Paczkomat", no wolf/hare/"Nu, pogodi", no InPost or other operator names in copy (`src/i18n` brand tests stay).
- Rules: 4 chutes `LU`, `LD`, `RU`, `RD`; 5 positions each; a parcel leaving position 5 with the courier at that chute scores +1, otherwise it breaks.
- Complaints counted in halves: miss = 2, miss while the customer is visible = 1; game over at 6 (three complaints). At scores 200 and 500 complaints reset to 0.
- Score display wraps 999 → 0; records keep the real total.
- Tick interval: start 800 ms (A) / 600 ms (B), × 0.96 per 10 points, floor 250 ms.
- Game A: at most 2 chutes carry parcels at once while score < 50; Game B: 4 from the start.
- Records per game (`record:A`, `record:B`) in the browser via `src/storage.ts`.
- Keys: `KeyQ`=LU, `KeyA`=LD, `KeyP`=RU, `KeyL`=RD, `Numpad7`/`Numpad1`/`Numpad9`/`Numpad3` the same; `Space`/`Enter` start Game A, `KeyB` starts Game B.
- Deploy: after green CI on a push to `main` from this repository, and manual dispatch (deploys `main`); no schedule.
- Commit messages end with a blank line and `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

```ts
// src/core/game.ts
/**
 * The rules of the courier game: four chutes, five positions each, one tick
 * at a time. A pure reducer — the clock, input and sound live in main.ts.
 */
import { next, nextInt } from './rng.js';
import type { RngState } from './rng.js';

export type Chute = 'LU' | 'LD' | 'RU' | 'RD';
export const CHUTES: readonly Chute[] = ['LU', 'LD', 'RU', 'RD'];
export type Mode = 'A' | 'B';
export const POSITIONS = 5;
/** Complaints are counted in halves: a miss costs 2, a miss the customer saw costs 1. */
export const GAME_OVER_HALVES = 6;
export const BONUS_SCORES: readonly number[] = [200, 500];
export const CUSTOMER_TICKS = 8;
const CUSTOMER_CHANCE = 0.03;
const PAUSE_MS = 1000;

/** Index 0 is the top of the chute, index 4 the lip. */
export type Lane = readonly boolean[];

export interface GameState {
  readonly mode: Mode;
  readonly rng: RngState;
  readonly courier: Chute;
  readonly lanes: Readonly<Record<Chute, Lane>>;
  readonly score: number;
  readonly halves: number;
  /** Ticks the customer stays visible. */
  readonly customer: number;
  /** Ticks left of the freeze after a miss. */
  readonly pause: number;
  readonly broken: Chute | null;
  readonly over: boolean;
}

export type GameEvent = 'step' | 'catch' | 'miss' | 'halfMiss' | 'bonus' | 'customer' | 'over';

const EMPTY_LANE: Lane = [false, false, false, false, false];
const emptyLanes = (): Record<Chute, Lane> => ({ LU: EMPTY_LANE, LD: EMPTY_LANE, RU: EMPTY_LANE, RD: EMPTY_LANE });

export function newGame(mode: Mode, seed: number): GameState {
  return {
    mode, rng: seed >>> 0, courier: 'LD', lanes: emptyLanes(), score: 0, halves: 0,
    customer: 0, pause: 0, broken: null, over: false,
  };
}

export function tickInterval(mode: Mode, score: number): number {
  const start = mode === 'A' ? 800 : 600;
  return Math.max(250, Math.round(start * 0.96 ** Math.floor(score / 10)));
}

export function spawnChance(mode: Mode, score: number): number {
  return Math.min(0.85, (mode === 'A' ? 0.35 : 0.5) + score * 0.002);
}

export function chuteLimit(mode: Mode, score: number): number {
  return mode === 'A' && score < 50 ? 2 : 4;
}

export function displayScore(score: number): number {
  return score % 1000;
}

export function move(state: GameState, chute: Chute): GameState {
  return state.over ? state : { ...state, courier: chute };
}

export function step(state: GameState): { state: GameState; events: GameEvent[] } {
  if (state.over) {
    return { state, events: [] };
  }
  if (state.pause > 0) {
    const pause = state.pause - 1;
    return { state: { ...state, pause, broken: pause === 0 ? null : state.broken }, events: [] };
  }

  const events: GameEvent[] = ['step'];
  let { score, halves, rng, customer } = state;
  let broken: Chute | null = null;
  for (const chute of CHUTES) {
    if (state.lanes[chute][POSITIONS - 1] !== true) {
      continue;
    }
    if (state.courier === chute) {
      score += 1;
      events.push('catch');
      if (BONUS_SCORES.includes(score)) {
        halves = 0;
        events.push('bonus');
      }
    } else {
      const cost = customer > 0 ? 1 : 2;
      halves += cost;
      events.push(cost === 1 ? 'halfMiss' : 'miss');
      broken = chute;
    }
  }

  if (halves >= GAME_OVER_HALVES) {
    events.push('over');
    return {
      state: { ...state, score, halves: GAME_OVER_HALVES, customer: 0, lanes: emptyLanes(), broken, over: true },
      events,
    };
  }
  if (broken !== null) {
    // A miss clears the board; the next parcels start from the top after a short freeze.
    return {
      state: {
        ...state, score, halves, broken, lanes: emptyLanes(), customer: Math.max(0, customer - 1),
        pause: Math.ceil(PAUSE_MS / tickInterval(state.mode, score)),
      },
      events,
    };
  }

  const lanes = Object.fromEntries(
    CHUTES.map((c) => [c, [false, ...state.lanes[c].slice(0, POSITIONS - 1)]]),
  ) as Record<Chute, Lane>;

  // At most one new parcel per tick: parcels move together, so no two ever
  // share a position across chutes and no two reach their lips at once.
  let roll: number;
  [roll, rng] = next(rng);
  if (roll < spawnChance(state.mode, score)) {
    const busy = CHUTES.filter((c) => lanes[c].some(Boolean));
    const candidates = busy.length >= chuteLimit(state.mode, score) ? busy : CHUTES;
    let index: number;
    [index, rng] = nextInt(rng, candidates.length);
    const chute = candidates[index];
    if (chute !== undefined) {
      lanes[chute] = [true, ...lanes[chute].slice(1)];
    }
  }

  if (customer > 0) {
    customer -= 1;
  } else {
    [roll, rng] = next(rng);
    if (roll < CUSTOMER_CHANCE) {
      customer = CUSTOMER_TICKS;
      events.push('customer');
    }
  }

  return { state: { ...state, rng, lanes, score, halves, customer, broken: null }, events };
}
```

```ts
// src/core/record.ts
import type { Mode } from './game.js';

export interface Records {
  readonly A: number;
  readonly B: number;
}

export const EMPTY_RECORDS: Records = { A: 0, B: 0 };

const isCount = (v: unknown): v is number => typeof v === 'number' && Number.isInteger(v) && v >= 0;

/** Whatever storage hands back; anything odd counts as no record. */
export function recordsFrom(value: unknown): Records {
  if (typeof value !== 'object' || value === null) {
    return EMPTY_RECORDS;
  }
  const v = value as Record<string, unknown>;
  return { A: isCount(v['A']) ? v['A'] : 0, B: isCount(v['B']) ? v['B'] : 0 };
}

export function withScore(records: Records, mode: Mode, score: number): { records: Records; isNew: boolean } {
  if (score <= records[mode]) {
    return { records, isNew: false };
  }
  return { records: { ...records, [mode]: score }, isNew: true };
}
```

```ts
 * The LCD as one SVG. Like a real handheld, nothing moves: every position a
 * parcel or the courier can take is printed once as a segment, and the game
 * only lights or darkens segments. Static artwork (vans, chutes, the locker,
 * the pavement) is the printed background. No colours here: CSS paints
 * `.lcd-print`, `[data-seg]` and `[data-seg][data-on]`.

import { CHUTES, POSITIONS } from '../core/game.js';
import type { Chute } from '../core/game.js';

type Point = readonly [number, number];

const CHUTE_LINES: Readonly<Record<Chute, { from: Point; to: Point }>> = {
  LU: { from: [30, 70], to: [130, 125] },
  LD: { from: [30, 160], to: [130, 215] },
  RU: { from: [370, 70], to: [270, 125] },
  RD: { from: [370, 160], to: [270, 215] },
};

const DIGIT_X: readonly number[] = [276, 298, 330, 352];
const DIGIT_Y = 10;
const DIGIT_SEGMENTS: Readonly<Record<string, readonly [number, number, number, number]>> = {
  a: [2, 0, 12, 3],
  b: [14, 2, 3, 15],
  c: [14, 19, 3, 15],
  d: [2, 33, 12, 3],
  e: [0, 19, 3, 15],
  f: [0, 2, 3, 15],
  g: [2, 16.5, 12, 3],
};

const seg = (id: string, body: string, transform = ''): string =>
  `<g data-seg="${id}"${transform === '' ? '' : ` transform="${transform}"`}>${body}</g>`;

function parcel(chute: Chute, position: number): string {
  const { from, to } = CHUTE_LINES[chute];
  const t = (position + 0.5) / POSITIONS;
  const x = from[0] + (to[0] - from[0]) * t;
  const y = from[1] + (to[1] - from[1]) * t - 10;
  const slope = (Math.atan2(Math.abs(to[1] - from[1]), Math.abs(to[0] - from[0])) * 180) / Math.PI;
  const angle = to[0] > from[0] ? slope : -slope;
  return seg(
    `p-${chute}-${String(position)}`,
    '<rect x="-8" y="-7" width="16" height="14" rx="2"/><path d="M-8 -1H8M0 -7V7" class="lcd-tape"/>',
    `translate(${x.toFixed(1)} ${y.toFixed(1)}) rotate(${angle.toFixed(1)})`,

}

  const left = chute.startsWith('L');
```

```ts
// src/ui/lcd.ts
import { CHUTES, POSITIONS, displayScore } from '../core/game.js';
import type { Chute, GameState, Mode } from '../core/game.js';
import { setAttr } from './dom.js';

export type LcdView =
  | { readonly kind: 'game'; readonly state: GameState; readonly blink: boolean }
  | { readonly kind: 'clock'; readonly hours: number; readonly minutes: number; readonly pose: Chute; readonly blink: boolean }
  | { readonly kind: 'record'; readonly mode: Mode; readonly record: number };

const DIGITS: Readonly<Record<string, string>> = {
  '0': 'abcdef', '1': 'bc', '2': 'abdeg', '3': 'abcdg', '4': 'bcfg',
  '5': 'acdfg', '6': 'acdefg', '7': 'abc', '8': 'abcdefg', '9': 'abcdfg', ' ': '',
};

const number3 = (n: number): string => String(n).padStart(4, ' ');

export function displayText(view: LcdView): string {
  switch (view.kind) {
    case 'game':
      return view.state.over && !view.blink ? '    ' : number3(displayScore(view.state.score));
    case 'record':
      return number3(displayScore(view.record));
    case 'clock':
      return `${String(view.hours).padStart(2, ' ')}${String(view.minutes).padStart(2, '0')}`;
  }
}

export function litSegments(view: LcdView): Set<string> {
  const lit = new Set<string>();
  [...displayText(view)].forEach((char, index) => {
    for (const s of DIGITS[char] ?? '') {
      lit.add(`d${String(index)}${s}`);
    }
  });

  if (view.kind === 'clock') {
    lit.add(`c-${view.pose}`);
    if (view.blink) {
      lit.add('colon');
    }
    return lit;
  }
  if (view.kind === 'record') {
    lit.add(`lbl-${view.mode}`);
    return lit;
  }

  const { state, blink } = view;
  lit.add(`lbl-${state.mode}`);
  lit.add(`c-${state.courier}`);
  for (const chute of CHUTES) {
    for (let i = 0; i < POSITIONS; i += 1) {
      if (state.lanes[chute][i] === true) {
        lit.add(`p-${chute}-${String(i)}`);
      }
    }
  }
  const whole = Math.floor(state.halves / 2);
  for (let i = 0; i < Math.min(whole, 3); i += 1) {
    lit.add(`m-${String(i)}`);
  }
  if (state.halves % 2 === 1 && blink) {
    lit.add(`m-${String(whole)}`);
  }
  if (state.broken !== null && blink) {
    lit.add(state.broken.startsWith('L') ? 'b-L' : 'b-R');
  }
  if (state.customer > 0) {
    lit.add('cust');
  }
  return lit;
}

/** Toggles `data-on` on each segment and exposes the digits for tests and assistive tech. */
export function renderLcd(svg: Element, view: LcdView): void {
  const lit = litSegments(view);
  for (const element of svg.querySelectorAll('[data-seg]')) {
    setAttr(element, 'data-on', lit.has(element.getAttribute('data-seg') ?? '') ? '' : null);
  }
  setAttr(svg, 'data-display', displayText(view));
}
```

```ts
// src/ui/controls.ts
import type { Chute, Mode } from '../core/game.js';

export type Command =
  | { readonly kind: 'move'; readonly chute: Chute }
  | { readonly kind: 'start'; readonly mode: Mode }
  | { readonly kind: 'clock' };

const KEYS: Readonly<Record<string, Command>> = {
  KeyQ: { kind: 'move', chute: 'LU' },
  KeyA: { kind: 'move', chute: 'LD' },
  KeyP: { kind: 'move', chute: 'RU' },
  KeyL: { kind: 'move', chute: 'RD' },
  Numpad7: { kind: 'move', chute: 'LU' },
  Numpad1: { kind: 'move', chute: 'LD' },
  Numpad9: { kind: 'move', chute: 'RU' },
  Numpad3: { kind: 'move', chute: 'RD' },
  Space: { kind: 'start', mode: 'A' },
  Enter: { kind: 'start', mode: 'A' },
  KeyB: { kind: 'start', mode: 'B' },
};

export function commandForKey(code: string): Command | null {
  return Object.hasOwn(KEYS, code) ? (KEYS[code] ?? null) : null;
}

export function quadrantChute(x: number, y: number, width: number, height: number): Chute {
  const left = x < width / 2;
  const upper = y < height / 2;
  return left ? (upper ? 'LU' : 'LD') : upper ? 'RU' : 'RD';
}

const isChute = (v: string | undefined): v is Chute => v === 'LU' || v === 'LD' || v === 'RU' || v === 'RD';

/** `pointerdown`, not `click`: a handheld button acts the moment it is pressed. */
export function bindControls(root: HTMLElement, lcd: Element, onCommand: (command: Command) => void): void {
  root.addEventListener('pointerdown', (event) => {
    const target = (event.target as Element | null)?.closest<HTMLElement>('[data-move],[data-start],[data-clock]');
    if (target === null || target === undefined) {
      return;
    }
    const chute = target.dataset['move'];
    const mode = target.dataset['start'];
    if (isChute(chute)) {
      onCommand({ kind: 'move', chute });
    } else if (mode === 'A' || mode === 'B') {
      onCommand({ kind: 'start', mode });
    } else if (target.hasAttribute('data-clock')) {
      onCommand({ kind: 'clock' });
    }
    event.preventDefault();
  });

  lcd.addEventListener('pointerdown', (event) => {
    const e = event as PointerEvent;
    const box = lcd.getBoundingClientRect();
    onCommand({ kind: 'move', chute: quadrantChute(e.clientX - box.left, e.clientY - box.top, box.width, box.height) });
  });

  window.addEventListener('keydown', (event) => {
    if (event.repeat) {
      return;
    }
    const command = commandForKey(event.code);
    if (command !== null) {
      event.preventDefault();
      onCommand(command);
    }
  });
}
```

```ts
/** Polish needs three forms (1 paczka, 2 paczki, 5 paczek); English two. */
export function pluralForm(lang: Lang, n: number): 'one' | 'few' | 'many' {
  if (n === 1) {
    return 'one';
  }
  if (lang === 'en') {
    return 'many';
  }
  const tens = n % 10;
  const hundreds = n % 100;
  return tens >= 2 && tens <= 4 && (hundreds < 12 || hundreds > 14) ? 'few' : 'many';
}

export function countParcels(n: number, lang: Lang = currentLang): string {
  return translate(lang, `count.parcels.${pluralForm(lang, n)}`, { n });
}
```

```ts
import { isMessageKey, t } from '../i18n/index.js';

/** Fills `data-t` text and `data-t-label` aria-labels. Re-run on a language switch. */
export function applyStaticText(root: ParentNode): void {
  for (const element of root.querySelectorAll<HTMLElement>('[data-t]')) {
    const key = element.dataset['t'];
    if (key !== undefined && isMessageKey(key)) {
      setText(element, t(key));
    }
  }
  for (const element of root.querySelectorAll('[data-t-label]')) {
    const key = element.getAttribute('data-t-label') ?? '';
    if (isMessageKey(key)) {
      setAttr(element, 'aria-label', t(key));
    }
  }
}
```

```ts
 * The handheld: timers, input, sound, record and sharing. Every rule lives in
 * core/game.ts; this file only decides when to call it.
 */
import './theme/fonts.css';
import './theme/tokens.css';
import './theme/app.css';

import { cueFor, createSfx } from './audio/sfx.js';
import { CHUTES, move, newGame, step, tickInterval } from './core/game.js';
import type { Chute, GameState, Mode } from './core/game.js';
import { recordsFrom, withScore } from './core/record.js';
import type { Records } from './core/record.js';
import { detectLang, getLang, otherLang, setLang, t } from './i18n/index.js';
import { STORAGE_KEYS, storage } from './storage.js';
import { bindControls } from './ui/controls.js';
import type { Command } from './ui/controls.js';
import { need, setAttr, setHidden, setText } from './ui/dom.js';
import { lcdMarkup } from './ui/lcd-art.js';
import { renderLcd } from './ui/lcd.js';
import type { LcdView } from './ui/lcd.js';
import { applyStaticText } from './ui/screens.js';
import { shareText, targetsFrom } from './ui/share.js';
import { shareText as buildShareText, slipText } from './ui/slip.js';

const RECORD_SHOW_MS = 1500;
const BLINK_MS = 500;
const POSE_MS = 4000;

const app = need<HTMLElement>(document, '#app');
const lcdHost = need<HTMLElement>(document, '#lcd');
lcdHost.innerHTML = lcdMarkup();
const svg = need<Element>(lcdHost, 'svg');
const slip = need<HTMLElement>(document, '#slip');
const slipTextNode = need<HTMLElement>(document, '#slip-text');
const slipRecord = need<HTMLElement>(document, '#slip-record');
const shareNote = need<HTMLElement>(document, '#share-note');
const shareFallback = need<HTMLTextAreaElement>(document, '#share-fallback');
const live = need<HTMLElement>(document, '#live');
const soundButton = need<HTMLButtonElement>(document, '#btn-sound');
const langButton = need<HTMLButtonElement>(document, '#btn-lang');

type Phase = 'clock' | 'record' | 'playing' | 'over';

let phase: Phase = 'clock';
let game: GameState | null = null;
let records: Records = recordsFrom(storage.get(STORAGE_KEYS.records));
let lastResult: { mode: Mode; score: number; isNew: boolean } | null = null;
let blink = true;
let pose: Chute = 'LD';
let tickTimer: number | undefined;
let recordTimer: number | undefined;

setLang(detectLang({ stored: storage.get(STORAGE_KEYS.lang), navigatorLanguage: navigator.language }));
const sfx = createSfx({ muted: storage.get(STORAGE_KEYS.mute) === true });

function view(): LcdView {
  if ((phase === 'playing' || phase === 'over') && game !== null) {
    return { kind: 'game', state: game, blink };
  }
  if (phase === 'record' && game !== null) {
    return { kind: 'record', mode: game.mode, record: records[game.mode] };
  }
  const now = new Date();
  return { kind: 'clock', hours: now.getHours(), minutes: now.getMinutes(), pose, blink };
}

function render(): void {
  app.dataset['state'] = phase;
  renderLcd(svg, view());
}

function paintStatic(): void {
  document.documentElement.lang = getLang();
  applyStaticText(document);
  setText(langButton, t('lang.toggle'));
  setAttr(soundButton, 'aria-pressed', sfx.isMuted() ? 'false' : 'true');
  document.querySelector('meta[name="description"]')?.setAttribute('content', t('meta.tagline'));
  if (lastResult !== null) {
    setText(slipTextNode, slipText(lastResult.score, records[lastResult.mode], getLang()));
  }
}

function stopTimers(): void {
  window.clearTimeout(tickTimer);
  window.clearTimeout(recordTimer);
  tickTimer = undefined;
  recordTimer = undefined;
}

function scheduleTick(): void {
  if (game === null || phase !== 'playing' || document.hidden) {
    return;
  }
  tickTimer = window.setTimeout(tick, tickInterval(game.mode, game.score));
}

function tick(): void {
  if (game === null) {
    return;
  }
  const result = step(game);
  game = result.state;
  for (const event of result.events) {
    const cue = cueFor(event);
    if (cue !== null) {
      sfx.play(cue);
    }
    if (event === 'catch') {
      setText(live, t('live.score', { score: game.score }));
    } else if (event === 'miss' || event === 'halfMiss') {
      setText(live, t('live.complaint', { count: String(game.halves / 2).replace('.', getLang() === 'pl' ? ',' : '.') }));
    }
  }
  if (game.over) {
    finish();
  } else {
    scheduleTick();
  }
  render();
}

function finish(): void {
  if (game === null) {
    return;
  }
  phase = 'over';
  const { records: next, isNew } = withScore(records, game.mode, game.score);
  records = next;
  storage.set(STORAGE_KEYS.records, records);
  lastResult = { mode: game.mode, score: game.score, isNew };
  setText(slipTextNode, slipText(game.score, records[game.mode], getLang()));
  setHidden(slipRecord, !isNew);
  setText(shareNote, '');
  setHidden(shareFallback, true);
  setHidden(slip, false);
  setText(live, t('live.over'));
}

function start(mode: Mode): void {
  stopTimers();
  game = newGame(mode, Date.now() >>> 0);
  lastResult = null;
  setHidden(slip, true);
  phase = 'record';
  render();
  recordTimer = window.setTimeout(() => {
    phase = 'playing';
    render();
    scheduleTick();
  }, RECORD_SHOW_MS);
}

function showClock(): void {
  stopTimers();
  game = null;
  lastResult = null;
  setHidden(slip, true);
  phase = 'clock';
  render();
}

function onCommand(command: Command): void {
  sfx.unlock();
  if (command.kind === 'start') {
    start(command.mode);
  } else if (command.kind === 'clock') {
    showClock();
  } else if (game !== null && (phase === 'playing' || phase === 'record')) {
    game = move(game, command.chute);
    render();
  }
}

async function share(): Promise<void> {
  if (lastResult === null) {
    return;
  }
  const text = buildShareText(lastResult.mode, lastResult.score, lastResult.isNew, getLang());
  const outcome = await shareText(text, targetsFrom(navigator));
  const notes = { shared: 'slip.shared', copied: 'slip.copied', manual: 'slip.manual', dismissed: null } as const;
  const key = notes[outcome];
  setText(shareNote, key === null ? '' : t(key));
  if (outcome === 'manual') {
    shareFallback.value = text;
    setHidden(shareFallback, false);
    shareFallback.select();
  }
}

bindControls(app, svg, onCommand);
need<HTMLButtonElement>(document, '#btn-share').addEventListener('click', () => void share());
soundButton.addEventListener('click', () => {
  sfx.setMuted(!sfx.isMuted());
  storage.set(STORAGE_KEYS.mute, sfx.isMuted());
  paintStatic();
});
langButton.addEventListener('click', () => {
  setLang(otherLang());
  storage.set(STORAGE_KEYS.lang, getLang());
  paintStatic();
});

// Leaving the tab freezes the shift; coming back resumes it where it stopped.
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    window.clearTimeout(tickTimer);
    tickTimer = undefined;
  } else {
    scheduleTick();
  }
});

window.setInterval(() => {
  blink = !blink;
  render();
}, BLINK_MS);
window.setInterval(() => {
  if (phase === 'clock') {
    const others = CHUTES.filter((c) => c !== pose);
    pose = others[new Date().getSeconds() % others.length] ?? 'LD';
  }
}, POSE_MS);

paintStatic();
render();
```

```ts
/** The chute key whose parcel sits on the lip right now, or null. */
export async function lipKey(page: Page): Promise<string | null> {
  const keys: Record<string, string> = { LU: 'q', LD: 'a', RU: 'p', RD: 'l' };
  for (const chute of Object.keys(keys)) {
    if ((await page.locator(`[data-seg="p-${chute}-4"][data-on]`).count()) > 0) {
      return keys[chute] ?? null;
    }
  }
  return null;
}
```
